# Git & GitHub: version control for everyone

A free, self-study course from HAMK on version control with Git and GitHub, from the first steps to managing
projects in the school's GitHub organization. Practise in simulated Git Bash, GitHub Desktop, VS Code and
github.com: nothing you do in the course touches real accounts.

**Open the course: https://hamk-vlk.github.io/git-github-course/**

## Privacy
- No accounts, cookies, analytics or tracking.
- Your progress is saved only in your own browser (localStorage). Nothing is sent to HAMK, GitHub or anyone else.
  The page's Content-Security-Policy forbids the browser from making any network request.
- To move progress to another device, use **Export progress file** / **Import progress file** in the progress panel.
- The site is hosted by GitHub Pages, which, like any web host, logs visitors' IP addresses
  ([GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)).

## Use it offline
**Code → Download ZIP**, unzip, and open `index.html` in Chrome, Edge, Firefox or Safari.
